## 「齿轮感」的三个来源

要让电子音色听起来像「金属零件在互相咬合」，需要同时满足三个条件。缺一个就会塌成普通的电子音。

### 一、失谐（Detune）：0.2% ~ 0.5%

把两个同频率的振荡器做极小的频率偏移，会产生缓慢的拍频。偏移量是关键：

| 失谐量 | 听感 |
| --- | --- |
| 0% | 死板，像蜂鸣器 |
| 0.1% | 轻微晃动，接近「呼吸」 |
| **0.4%** | **金属厚度，咬合的摩擦感** |
| 1%以上 | 明显跑调，失去机械的精确感 |

```js
// 两个振荡器，一个标准频率，一个轻微上偏
osc1.frequency.value = base;
osc2.frequency.value = base * 1.004; // 0.4% 失谐
```

### 二、包络：极短的 Attack

机械音的起音必须是**瞬间的**。Attack 超过 15ms，就会从中性打击感变成弦乐的弓弦感。

```text
Attack:   0.005s   ← 几乎瞬时，这是"撞击"
Decay:    0.30s
Sustain:  0.05
Release:  0.15s
```

### 三、节奏的门限化

真正的机械感来自**不该响的地方响、该响的地方停**。把一段连续音符用不规则的门限切开：

```text
原始:  ●●●●●●●●●●●●●●●●   （连续十六分）
门限:  ●·●●·●··●●·●●·●·
结果:  断续，但保持了对齐的骨架
```

这个操作的本质是：**让听者感觉到「有个东西在控制节奏」，而不是「节奏本身在流动」**。

## 常见误区

> **误区一：把音色做脏就会有机械感。**
> 恰恰相反。机械感来自**精确**。加噪声只会让它听起来像坏掉的机器，而不是精密运转的机器。

> **误区二：BPM 越快越机械。**
> 齿轮咬合的关键是「每一下都对得上」。慢速曲子只要对齐精确，机械感反而更强。

## 小结

机械感 = **失谐带来的物理厚度** + **瞬态起音带来的撞击感** + **不规则门限带来的秩序感**。

三个都很简单，难的是同时做对，并且知道什么时候**不**做。
